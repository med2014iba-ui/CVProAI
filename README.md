# CV Pro AI

A Kotlin + Jetpack Compose Android app for creating, managing, and exporting professional CVs.

## Phase 1 included
- Home screen
- CV creation flow
- Personal info, experience, education, skills, languages, certifications, projects, interests, references
- Local persistence
- Modern light/dark theme
- Multi-language preparation for English, French, Arabic

## Running the app
1. Open the project in Android Studio.
2. Let Gradle sync.
3. Choose an Android emulator or physical device.
4. Click Run.

## Notes
This is a functional Phase 1 MVP. Later phases will include templates, AI enhancements, PDF export, cover letters, and premium architecture.
